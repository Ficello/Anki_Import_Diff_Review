Diff Hunk — Anki Import Diff Review & AnkiCollab Safety Gateway

Never lose personal study notes, mnemonics, or custom edits during deck updates again.
By default, importing an Anki package or syncing a shared deck blindly overwrites existing cards. Diff Hunk creates an isolated safety sandbox: it calculates exact differences between your cards and incoming updates, highlights additions and deletions with high-visibility color coding, and lets you selectively accept or reject modifications at the note, field, or individual text hunk level.

Safety First — Non-Destructive Dry Run :
Diff Hunk uses native SQLite transaction savepoints. If you cancel or close the review window, 100% of the import is aborted and your database remains strictly identical to its pre-import state.

Workflow Overview

STEP 1
Import or Sync
You trigger an import (.apkg, .colpkg, .csv) or sync a collaborative deck via AnkiCollab.
STEP 2
Safety Sandbox
Diff Hunk simulates the operation in a temporary savepoint without touching your active collection.
STEP 3
Visual Review
Color-coded interface opens: green for additions, red for deletions. Review card by card or hunk by hunk.
STEP 4
Selective Commit
Only accepted modifications are applied to your collection. Canceling leaves zero modifications behind.

How to Use Diff Hunk

1. Reviewing Granular Text Changes (Hunk by Hunk)

When an incoming note modifies an existing card, Diff Hunk splits the changes into atomic hunks:

  • Accept a hunk ([+]) : Adopts the incoming change (highlighted with a green left gutter and green text).
  • Reject a hunk ([−]) : Keeps your existing text (marked with a red gutter, retaining your original version).
  • Field-level control : Use Accept Field or Keep Original to batch-decide an entire field at once (e.g., accepting an updated medical guideline while preserving a custom clinical note field).
  • In-place manual editing : You can directly edit the text in the dialog before confirming. If you want to refine wording or merge personal notes with official updates, click into the editor and type freely.

2. Tags Management & Inspection

Tag modifications are isolated into a dedicated panel with clear status badges:

  • Added tags : Highlighted in bold green chips with a + prefix.
  • Removed tags : Displayed in red with strikethrough styling and a − prefix.
  • Global tag option : By default, Accept all tags on confirm is enabled, ensuring new categorization tags are adopted without forcing unwanted text replacements.

3. Lightning-Fast Keyboard Workflow (Review Mode)

Toggle Review Mode in the top-right header to process hundreds of modifications without touching your mouse:

  • Tab / Shift + Tab : Jump to the next / previous diff hunk.
  • Y : Accept the active hunk and automatically jump to the next hunk.
  • N : Reject the active hunk and automatically jump to the next hunk.
  • Space : Toggle accepted/rejected state of the active hunk in place.
  • F2 or Alt + A : Accept all changes for the current card.
  • F3 or Alt + R : Reject all changes for the current card.
  • F4 or Alt + Shift + T : Accept only tag changes for the current card.
  • Down / Up or Right / Left : Navigate between modified cards.
  • Enter : Finalize and commit all validated changes.
  • Esc : Abort the entire import process.

4. Anki Browser Dock (Card Explorer Integration)

Diff Hunk is also deeply integrated into Anki's native Card Browser (Browse / Parcourir):

  • Docked Diff Panel : An interactive panel docks beside the card editor showing recent version diffs and field comparisons.
  • History & Collab Tab (Alt + H) : Inspect chronological snapshots and past synchronization events for the selected card.
  • Copy Old Fields (Alt + C) : Instantly copies the pre-update content of a note to your system clipboard.
  • Smart Filtering : Toggle Only changed fields to hide static fields, or Learned cards only to ignore untouched new cards and focus on active material.

5. AnkiCollab Seamless Integration & Protected Fields

Fully compatible with the official AnkiCollab add-on (ID 1957538407):

  • Automatically intercepts remote collaborative updates before they alter your database.
  • Respects protected fields configured in AnkiCollab: protected fields display an amber Protected badge and auto-reject upstream changes to prevent accidental overwrites.

Configuration Reference

Configure settings via Tools > Add-ons > Diff Hunk > Config:

  • visual_diff_enabled (boolean, default: true) : Enables the visual review dialog when importing .apkg, .colpkg, or .csv files.
  • ankicollab_diff_enabled (boolean, default: true) : Intercepts incoming AnkiCollab synchronization batches.
  • only_changed_fields (boolean, default: true) : Hides identical fields to maximize review efficiency.
  • learned_cards_only (boolean, default: true) : Restricts review verification to cards you have already studied (ignoring unstudied new cards).
  • accept_all_tags_on_confirm (boolean, default: true) : Adopts incoming tag updates upon confirmation regardless of text hunk decisions.

Compatibility

  • Anki 23.10+, Anki 24.x, Anki 25.x+ (Qt6)
  • Windows, macOS, and Linux
  • Seamless compatibility with AnkiCollab (addon 1957538407) and Customize Keyboard Shortcuts (addon 1762336370)
